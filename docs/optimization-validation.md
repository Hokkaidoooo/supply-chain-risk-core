## 本地结果

- Python 3.10.9，Windows 10.0.19045，NetworkX 3.4.2。
- 安装成功生成 `supply_chain_risk_core-0.2.0-py3-none-any.whl`；临时隔离环境不复用历史 `.venv-risk`。
- 安装后仓库外运行 28 项 unittest，全通过；合成示例实际输出终端暴露 0.24、EBIT 1.5、利息保障倍数 5.0。
- 固定基线：26 节点、105 边、分支 5、跳数 5；产生 3905 条路径，检查 3905 条候选边。一次 Windows 测量耗时约 0.0251 秒，tracemalloc 峰值 14624 字节（仅被测调用，不含图构建）。只作环境基线，不作为普遍性能承诺。
- 来源清单保留原模块哈希，财务/传播的新哈希与适配关系随修改同步；契约与缺失值模块搬移后字节哈希仍与原快照一致。

## 复验命令

```sh
python -m pip install .
python -m unittest discover -s tests -v
python -m compileall -q src
python tools/check_manifest.py
python tools/benchmark_paths.py
```

在仓库外运行 `python -m supply_chain_risk_core.demo`。CI 执行同一安装包入口。

默认预算上限为 100000 次候选边检查，可设 `max_expansions=None` 关闭。财务历史兼容及年度口径回退默认关闭，详见 [API 约定](api.md)。预算和严格财务入口属于本次公开 API 的行为变更；包版本提升到 0.2.0。

企业事实消费目前只支持直接担保、应收关系。此处“完成”以清单要求的最小关系路径为范围，不代表多跳信用模型、真实企业证据核验或预测性能已经实现。
