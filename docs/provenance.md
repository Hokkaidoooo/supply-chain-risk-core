# 来源与整理范围

公开整理日期：2026-10-15。

本项目来自个人工行杯参赛工程。参赛者已确认项目为个人完成，赛事不限制公开。第三方数据的再分发许可与代码开放分别处理。

## 从基础库扩展到完整演示

0.1 版仅收录路径、财务、缺失值和提交契约四个模块。0.2 版增加可安装包、严格财务默认值、路径预算和直接企业事实关系。0.3 版接入工商特征、财务特征、评分与授信规则，补充投入产出、阶段二分析、报告导出和复现命令。

原比赛目录保持不变。公开版以显式输入替代本机数据路径，复用已有财务与契约核心，没有复制另一套财务口径。代码对应关系和字节指纹记录在 [SOURCE_MANIFEST.json](../SOURCE_MANIFEST.json)。

| 公开代码 | 原工程依据 | 主要整理 |
| --- | --- | --- |
| credit/deep_features.py | src/deep_features.py | 保留特征算法，调整包导入，移除读取比赛数据的自测入口 |
| credit/financial_features.py | src/features.py | 提取财务特征、缺失状态和日期辅助函数 |
| credit/scoring.py、credit/decision.py | 同名原模块 | 保留评分与规则；输入坏数值明确失败 |
| credit/rules.py | src/config.py | 提取所需规则常量，移除本机路径和预设全局修改 |
| input_output.py、scenarios.py | src/transmission_impact.py | 参数化矩阵与情景，区分固定源头价格与总需求 |
| stage2/projection.py | src/stage2/projection.py | 保留稳定节点、逐跳依据和同源投影规则 |
| stage2/quantitative.py | src/stage2/quantitative.py | 提取不依赖企业原件的成本、组合与区间计算 |
| workflow、evidence、study、reporting、cli | 公开版适配 | 一个输入文档、一份计算结果，以及可验证的报告目录 |

公开输入通过 schema 约束，未知项明确记录。特征算法仍保留原工程的哨兵值和中性编码；这不是重新训练或取得新预测证据。行业政策先验默认关闭，历史参数不是银行通用阈值。

## 演示与实际成品

- 包内 `data/example.json` 是合成输入的唯一维护入口。企业、金额、来源网址与示例页码均为演示设定。
- `examples/results` 是该输入经真实代码生成的结果快照，可用 CLI 重算。
- `case-studies/finals` 是本人编制的 2026-10-11 决赛分析成品：五本工作簿、Word 和 13 张图；逐件指纹见该目录清单。
- 原始赛事表、企业披露原件、付费查询材料、身份资料和含原始输入的授权评审 ZIP 不包含在公开仓库内。

示例来源检查只验证输入内容的哈希、日期与引用关系，不表示网页已在线认证。实际案例中引用的公开资料保留来源说明，不因此声称获得第三方原始材料的再分发许可。

## 可复核范围

可以复核公开函数、原算法对应关系、合成输入到结果的计算、报告一致性与文件完整性。独立核心的路径暴露不等于违约概率，工程复现不等于预测准确率、银行收益或比赛排名。
