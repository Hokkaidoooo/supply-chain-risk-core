# 来源与公开范围

公开整理日期：2026-10-14。

本项目来自个人工行杯参赛工程。参赛者确认项目为个人完成，赛事不限制公开。该确认与第三方数据的再分发许可分别处理，因此本仓库不携带原始数据表或企业材料。

## 与原工程的关系

- `financial_metrics.py`、`submission_contract.py`、`missing_values.py` 按原源码快照保留。
- `supply_chain.py` 从原传播逻辑适配：合并上下游重复遍历，通过参数指定聚合端点，解除固化行业表、行业别名、NumPy、Pandas 和全局配置依赖。
- 新增公开输入检查，保留路径方向、连乘、最强路径、防环及证据标记语义。
- 路径报告不再写死原数据年份；年份未知时返回 `None`。
- 财务模块保留历史兼容和有标记的年度口径回退；示例使用严格的新口径输入。
- 本公开版本没有包含原工程需求传导图、Leontief 总效应计算或完整信贷决策流水线。

这份独立版本不是原比赛源码的逐字节完整副本。`SOURCE_MANIFEST.json` 记录相关原模块与公开模块的指纹及关系，便于区分保留与适配。

## 研究依据与权利边界

原完整项目使用过投入产出分析与公开财务资料。本仓库只说明方法，不再分发国家统计局原表、取数包、聚合行业系数表或企业披露文件。

核心概念可参考投入产出分析中的直接消耗系数与完全消耗系数定义。路径边权连乘和取最大值仅用于路径暴露，不能替代 Leontief 逆，也不能自行转化为违约概率。

所有 `demo.py` 示例和测试夹具均为合成数据。测试中的来源字符串只标识测试情境，不是官方证据或赛事确认记录。

## 可复核范围

可以复核本仓库的函数行为、参数约束、边界测试与示例数值。无法仅凭此仓库复现未附数据的完整参赛结果，也不能推断比赛成绩或预测竞争力。
