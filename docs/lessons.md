# 项目中的几个关键问题

## 相同工商评分不能代表相同偿付能力

上市主体的注册资本、经营年限和登记状态相似，单靠工商评分很难反映持续亏损或付息缺口。原工程因此把定期报告证据单列为财务规则，保留其与工商风险信号的区别。

公开演示中的两家企业工商评分相同，财务规则给出不同决策。这个例子解释模型结构，不作为真实预测效果的证据。

## 未披露与明确为零需要分开

实缴、参保、利息、贡献率等缺失项若直接补零，可能制造资本空心、无限偿付能力或零利润影响等错误结论。特征内部保留已披露标记和未知哨兵，输出同时列明缺失项。没有查到风险记录也不能据此认定风险不存在。

## 收入变化与利润变化不是同一个量

需求冲击可以在销售份额假设下计算收入损失；利润影响还取决于可避免成本和贡献率。贡献率未知时，本项目保留金额影响中的未知部分，避免用一个精确数字掩盖缺失的业务条件。

## 一处定义应当产生一致的图表与正文

节点身份、边方向、最高/最低节点和依赖强度若在图、表和正文中分别维护，会出现拓扑与文字不一致。阶段二采用同一规范输入生成可见结果，并拒绝把缓存派生字段当作输入。

## 工程复现和预测验证需要不同证据

输入指纹、源码指纹、结果回读和重复运行可以证明版本一致；规则命中和历史比赛反馈可以帮助复盘；独立真值样本才能支持预测评价。公开材料分别说明这几类证据的用途，保留尚未获得充分验证的结论边界。
